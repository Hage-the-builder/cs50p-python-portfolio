
# CS50P — Python Programming Portfolio

This repository contains my programming work from [CS50’s Introduction to Programming with Python](https://cs50.harvard.edu/python/), a course offered by Harvard University.

## About

I completed CS50P to strengthen my understanding of Python and develop my ability to solve problems through code. The course challenged me to break down problems, write structured programs, debug errors, and apply programming concepts to practical tasks.

## What I Learned

- Python fundamentals, variables, functions, and control flow
- Exception handling and input validation
- Libraries, unit testing, and debugging
- File handling and object-oriented programming
- Problem-solving through independent coding practice

The programs in this repository demonstrate my progress throughout the course. Each project gave me an opportunity to apply programming concepts, work through implementation challenges, and improve my code.
